# os1-cpu-scheduler-6UDU

مشروع مادة **نظم التشغيل 1 (OS1)** لتنفيذ ومقارنة خوارزميات جدولة المعالج (**FCFS** و**SRTF**) بلغة Python.

## أعضاء المجموعة (6UDU)
- سوار عيسى يونس
- لوران يوسف داوود

## ملفات المستودع
- `scheduler.py`: الكود البرمجي لتنفيذ خوارزميتي FCFS وSRTF وحساب مقاييس الأداء.
- `input.txt`: ملف إدخال العمليات (`PID`، زمن الوصول، مدة التنفيذ).
- `report.md`: تقرير توثيقي يشرح الخوارزميات ونتائج المقارنة.
- `README.md`: نظرة عامة وتعليمات تشغيل المشروع.

## كيفية التشغيل
```bash
python scheduler.py
```
